# Quizzing
This project lets you test your multiplication skills. 
The project lets you select dificulty level and number of questions you want to test yourself by.
You fail the test under 50% and ace it over 80%.

## Instruction
Download or clone the repository to your PC by running:
```bash 
git clone https://github.com/RohaidAhmed/Quizzing.git
```
### Using bat file (Windows OS).
Find `quiz.bat` file in the project directory and run it.
### Using bash (Linux OS)
Find `quiz.sh` file in the project directory and run it.


### Run manually
#### Requirments
* Windows
    - Run the command to install dependencies.
    ```bash
    python -m pip install -r requirements.txt
    ```
* Linux 
    - Run the below command to install dependencies.
    ```bash
    python3 -m pip install -r requirements.txt
    ```

#### Usage
* Windows
    - Run 
    ```bash
    python main.py
    ```
* Linux
    - Run 
    ```bash
    python3 main.py
    ```
